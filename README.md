# 💰 Interactive Expense Tracker

A modern and responsive browser-based Expense Tracker built using HTML5, CSS3 and JavaScript.

The application allows users to add, edit, delete, search and filter their expenses. Expense data is stored in the browser using LocalStorage.

---

## 🚀 Features

- Add new expenses
- Edit existing expenses
- Delete individual expenses
- Delete all expenses
- Expense categories
- Category filtering
- Date filtering
- Search expenses
- Automatic total expense calculation
- Total transaction count
- Average expense calculation
- LocalStorage persistence
- Responsive design
- Form validation
- Dynamic UI updates
- Indian Rupee currency formatting
